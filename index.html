알기 쉬운 안드로이드 앱 기초

박경훈 · 주동현 · 김영준 지음 / 라임하우스 / 문서 표기 발행일 2025.12.15

원문 PDF 보기 ↗ (새 창)

한눈에 보는 내용

안드로이드 앱을 처음 만드는 학습자를 위한 Java·XML 중심의 실습 교재입니다. 개발 환경 준비에서 시작해 화면과 이벤트, 메뉴와 애니메이션, 화면 전환과 목록 표시를 익히고, 마지막에는 공공데이터를 이용한 구조동물 조회 앱으로 배운 내용을 연결합니다.

학습 흐름: 환경 설정 → 화면 구성 → 사용자 상호작용 → 화면·데이터 연결 → 종합 앱 실습

장별 핵심 요약

제목을 선택하면 내용을 펼칠 수 있습니다. 쪽수는 PDF 페이지 기준입니다.

01개발 환경과 앱의 구성 요소 9–26쪽

Activity, Service, Content Provider, Broadcast Receiver의 역할을 소개하고 Android Studio, SDK, AVD를 준비합니다. 도구 설치와 가상 기기 설정을 통해 앱을 실행할 실습 환경을 갖추는 단계입니다.

핵심: 앱의 구성 요소를 구분하고 개발 도구와 실행 환경의 관계를 이해합니다.

1장 원문 보기 · 9쪽 ↗ (새 창)
02프로젝트 구조와 화면 설계 27–52쪽

프로젝트의 소스·리소스 구조, AndroidManifest.xml과 Gradle 설정을 살펴봅니다. Activity에 XML 레이아웃을 연결하고 View와 위젯을 배치하며, LinearLayout과 RelativeLayout 실습으로 화면 구성의 기본을 익힙니다.

핵심: 화면 배치는 XML로, 동작은 Java 코드로 다루며 ID를 통해 위젯을 연결합니다.

2장 원문 보기 · 27쪽 ↗ (새 창)
03사용자 이벤트 처리 53–74쪽

버튼 클릭 등의 입력을 처리하는 여러 방식을 비교합니다. 익명 클래스, 재사용 가능한 리스너 참조 객체, Activity의 인터페이스 구현, XML의 onClick 속성을 다루며 코드 규모와 공통 동작 여부에 따라 선택하는 방법을 설명합니다.

핵심: 개별 버튼의 동작과 여러 뷰가 공유하는 동작을 구분해 리스너를 구성합니다.

3장 원문 보기 · 53쪽 ↗ (새 창)
04메뉴와 대화상자 75–124쪽

앱의 주요 기능을 제공하는 옵션 메뉴, 특정 항목에 관련된 컨텍스트 메뉴, 작업 위치에 표시하는 팝업 메뉴를 구분합니다. AlertDialog와 날짜·시간 선택 대화상자로 알림, 확인, 선택과 입력을 받는 UI를 구현합니다.

핵심: 기능의 범위와 사용자 작업 맥락에 맞는 메뉴·대화상자를 선택합니다.

4장 원문 보기 · 75쪽 ↗ (새 창)
05애니메이션과 시각적 피드백 125–154쪽

View Animation으로 이동·크기·회전·투명도 변화를 표현하고, Drawable Animation으로 이미지 프레임을 재생합니다. Interpolator로 속도 변화를 조절하며, Property Animation과 ObjectAnimator로 객체의 실제 속성을 제어하는 방식을 익힙니다.

핵심: 화면에 보이는 효과와 실제 객체 속성 변경의 차이를 이해합니다.

5장 원문 보기 · 125쪽 ↗ (새 창)
06액티비티와 인텐트 155–180쪽

Activity의 생명주기를 이해하고 Intent로 화면과 기능을 연결합니다. 명시적 인텐트로 앱 내부 화면을 전환하고 Parcelable 데이터를 전달하며, 암시적 인텐트로 웹·전화·지도·공유 기능을 요청하고 카메라 활용 예제를 다룹니다.

핵심: 화면 전환, 데이터 전달, 외부 기능 호출을 구분해 앱의 흐름을 설계합니다.

6장 원문 보기 · 155쪽 ↗ (새 창)
07어댑터와 목록 표시 181–216쪽

Adapter가 데이터와 화면 항목을 연결하는 원리를 설명합니다. ArrayAdapter, CursorAdapter, BaseAdapter 등의 용도를 비교하고, ListView의 기본 표시부터 항목 추가·수정·삭제를 지원하는 목록으로 확장합니다. 뷰 재활용을 통한 자원 절약도 다룹니다.

핵심: 데이터, 항목 레이아웃, 어댑터의 역할을 나누어 목록을 구성합니다.

7장 원문 보기 · 181쪽 ↗ (새 창)
08공공데이터를 활용한 종합 실습 217–252쪽

공공데이터포털의 활용 신청과 인증키 준비에서 시작해 구조동물 조회 앱을 제작합니다. Retrofit으로 비동기 요청을 보내고 JSON 응답을 데이터 모델에 매핑한 뒤, 사용자 정의 어댑터로 동물 이미지·품종·보호소를 표시합니다. 날짜 범위 선택으로 결과를 다시 조회하고 통신 실패와 빈 결과도 고려합니다.

핵심: 요청 → 응답 모델 → 어댑터 → 화면 갱신의 흐름으로 앞선 학습을 통합합니다.
