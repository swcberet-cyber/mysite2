# 회사 홈페이지

HTML, CSS, JavaScript로 제작한 반응형 회사 홈페이지입니다.

- `index.html`: 상단 메뉴, 회사소개, 서비스 3개, 문서 요약, 이메일·전화 문의
- `styles.css`: 남색·흰색 디자인 및 모바일 레이아웃
- `script.js`: 모바일 메뉴와 연도 표시
- `npm run build`: JavaScript 문법과 페이지 구조 검증 후 `dist/` 생성 (별도 패키지 설치 불필요)
- `data/`: 원문 PDF. 문서 요약 메뉴에서 전체 요약, 8개 장별 요약 및 원문 페이지를 확인할 수 있습니다. 빌드 시 링크된 PDF를 `dist/data/`로 복사하며 원문 누락 시 빌드가 실패합니다.

회사명 ‘나비스 파트너스’와 연락처는 예시입니다. 실제 정보는 `index.html`에서 교체하세요.
데이터베이스, 로그인, AI API 및 문의 데이터 수집 기능은 사용하지 않습니다.
